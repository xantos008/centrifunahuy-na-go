# ADR-0011: NATS usage

- Status: superseded by ADR-0002 (inherited)
- Date: 2026-11-15

## Revision 2026-11-15 (user decisions)
The NATS broker and JetStream consumer are inherited (nats.go v1.55.0). New code: the NATS controller (PRO-22) and NATS fan-out for PG (PRO-26/40).

The original Phase 0 text below is kept for history.

## Decision
- `github.com/nats-io/nats.go` (Apache-2.0).
- NATS broker: at-most-once, no history (capability descriptor forbids history/recovery namespaces on it), optional `allow_wildcards`, raw mode with `channel_replacements`.
- NATS controller (PRO-22) and NATS fan-out for PG broker/map broker (PRO-26/40) share one connection manager.
- JetStream consumer for async consumers: ack after successful executor call; redelivery = at-least-once; document ordering per subject.
