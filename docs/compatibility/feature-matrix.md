# Feature matrix — UPSTREAM (OSS v6.10.3) + PRO (v6.10.3) + EXTENSION

Generated in Phase 0 (2026-11-15) from the three research annexes:
- [oss-core-research.md](../research/oss-core-research.md)
- [oss-infra-research.md](../research/oss-infra-research.md)
- [pro-feature-inventory.md](../research/pro-feature-inventory.md)

Each row cites a source path: docs at `centrifugal.dev@69da714`, OSS source at `v6.10.3`, or release notes. The annexes hold the full per-feature detail: complete API method tables, the protocol message list, error/disconnect code tables, JWT claims, proxy fields and consumer semantics. This matrix is the index and status tracker.

**Totals:** 196 UPSTREAM rows, 143 PRO rows and 17 EXTENSION rows (sub-features included). About 32 rows are non-GA upstream (experimental, beta or preview).

**Categories** (user requirement C, 2026-11-15):
- `UPSTREAM`: confirmed in Centrifugo OSS v6.10.3. After DEC-01 this code is inherited from the fork (ADR-0002), and compatibility is proven by the compatibility suite ([docs/testing/compatibility-suite.md](../testing/compatibility-suite.md)).
- `PRO`: confirmed in public Centrifugo PRO v6.10.3 docs or release notes. We implement it from the docs only (ADR-0024).
- `EXTENSION`: our own additions, never described as compatible. See [§Extensions](#extensions).

The old `Edition` column (`OSS`/`PRO`) became `Category`: OSS rows map to UPSTREAM, PRO rows to PRO.

**Impl status values:**
- `inherited`: present in the imported OSS v6.10.3 code. Not yet proven by the compatibility suite.
- `verified`: the compatibility scenarios for the row are green in diff mode (ref vs sut) on all applicable engine profiles.
- `not started`, `in progress`, `implemented`: for PRO and EXTENSION rows, per the acceptance criteria in SPEC §12.
- `not applicable`: with evidence, e.g. features removed upstream or PRO licensing.
- `excluded (not released)`: WIP or draft upstream (PRO-27.05 relay, PRO-29, PRO-30); ADR-0024.
- `mapping`: a SPEC module with no distinct upstream feature.

**Source prefixes:**
- `D:` / `DOCS:` = docs
- `O:` / `OSS:` = OSS source
- `L:` / `LIB:` = centrifuge library
- `PROTO:` = protocol repo
- `R:` / `RN` = release notes
- `[src]` = behavior observed in source code, not a documented contract

**Open-question prefixes:** `CORE-OQ-nn`, `PRO-OQ-nn`, `OQ-ENG-…`/`OQ-AUTH-…` (infra), `INFRA-CONFLICT-nn`. See [open-questions.md](../research/open-questions.md).

The **Security** and **Tests** columns give the minimum required for the row to reach `implemented`. The test types are defined in `docs/testing/` (Phase 1).
